## Concept (3 sentences)
Any agent can `call_rite {kind: vigil|festival|blessing, subject, place}` to summon
the town to mark a live event — mourn a death, celebrate a canonized motif, bless a
peace. At the round boundary `resolve_rites()` counts co-located attendees, grants
the shared buff, and plants ONE shared belief in every attendee, so the gathering
becomes real chat material in each agent's own voice. The 3-D scene shows it as a
dusk vigil: lanterns and rising embers at the rite's place.

## Scope
1. **Verb** `call_rite` (action enum + dispatch, `runtime.py:137` pattern): validates
   kind/place, one ACTIVE rite per town at a time (a second call while one is
   pending is rejected with a clear reason — visible, `cause: rejected`), rite
   resolves at the NEXT round boundary. No `join_rite` verb (judge cut) —
   attendance = being at the place at resolution (agents hear the summons via a
   one-line perception note so they can choose to walk).
2. **Round boundary** `resolve_rites()` runs **AFTER `diffuse_culture()`** (judge
   directive b — pinned order + an order-invariant test with BOTH flags on).
   Attendees = living agents at the place (sorted, arithmetic only). Effects:
   existing small-buff mechanism (reuse, no new buff engine) + ONE shared belief via
   `_plant_belief` per attendee.
3. **Belief rules (judge directives a+c):** rite-born beliefs are tagged
   `source="rite"`, **exempt** from lived-culture's `belief_cap_per_agent`
   eviction pool (they cannot be silently evicted by a diffusion burst), and carry
   their own TTL `rites.belief_ttl_ticks` (default 60) so grief fades with time.
4. **Feed:** new **Rites 🔥 lane** (judge directive d — do NOT overload Culture):
   `rite_called {agent, kind, subject, place}` + aggregated `rite_concluded
   {kind, subject, place, attendee_count, notable_attendees≤3}`. Two lines per
   rite, ever — the aggregation pattern, not a per-agent flood.
5. **3-D vigil** (web): at an active/just-concluded rite's place — instanced
   lanterns + rising-ember particles (clone the golden-hour mote field pattern) +
   a warm point-light beacon; villagers already cluster by position. Seeded,
   reduced-motion-safe, OFF the replay surface (pure client projection of the
   rite events). **Cut list (in order, judge §6):** dusk-sky lerp is ALREADY cut
   (do not build); then festival poster; the lantern+ember floor MUST land.
6. **First-morning guarantee (judge directive e):** a deterministic nudge so ≥1
   rite provably occurs early — on the first agent death after flag-on (or, if
   none within `rites.nudge_ticks` default 200, a canonized-motif festival
   trigger), the god channel posts a summons the caller verb can answer; if no
   agent calls one within a further window, the god channel itself calls a
   memorial rite (visible as a god event, ON the replay surface like other god
   verbs). No silent injection — everything is an event.

## The law
1. Flag OFF ⇒ byte-identical (no enum entry, no prompt line, no event, no state
   key). Goldens + full suites unchanged.
2. Deterministic: seeded rite ids, sorted attendee iteration, arithmetic effects;
   `RiteState` serializes-when-nonempty, absent ⇒ none (old snapshots fine).
3. Zero added LLM calls: `call_rite` replaces a normal action turn; resolution and
   vigil are pure code. Chat can only get richer, never taxed.
4. Prompt cost: the summons perception line ≤ ~25 tokens, only while a rite is
   pending.
5. Every new yaml knob wired into the loader parse + regression test (9f56f10 rule).
6. 3-D vigil requires a rendered Playwright screenshot before "done"
   (visual-validation rule).
